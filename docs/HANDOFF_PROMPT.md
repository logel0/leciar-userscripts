# Codex引き継ぎ用プロンプト

新しいCodexプロジェクトまたはタスクで、以下を最初のメッセージとして使用します。

## 標準版

```text
このタスクでは、Leciel Arcadia向け非公式ユーザースクリプト集 `leciar-userscripts` の開発を継続してください。

最初に `AGENTS.md`、`docs/DEVELOPMENT_STATUS.md`、作業内容に関係する場合は `docs/BATTLE_LOG_FORMAT.md`、直近の `CHANGELOG.md` とGit履歴を確認してください。これらを過去の会話より優先する引き継ぎ情報として扱ってください。

mainは公開版、betaは検証版です。現在の作業対象はbetaです。解析用の保存ログはGit管理外の `<local-log-dir>` にあります。保存ログや画像はコミットしないでください。

ログ解析では、同じパラメータ番号が重複し得ること、行動番号はログの `(n行動目)` を正とすること、状態参照時点A・B・Cを目的別に区別することに注意してください。確定事項と推定を混同しないでください。

変更後は関連する保存ログで確認し、`node --check` と `git diff --check` を実行してください。commitは作業単位で行って構いませんが、私が明示的に依頼するまでpushしないでください。

まずリポジトリとブランチの状態、引き継いだ実装状況、未確定事項を短く報告してから、私の次の依頼に対応してください。
```

## 短縮版

```text
`AGENTS.md` と `docs/DEVELOPMENT_STATUS.md` を読み、必要に応じて `docs/BATTLE_LOG_FORMAT.md` も確認して、Leciel Userscriptsのbeta開発を引き継いでください。ローカルログは `<local-log-dir>`、ログ本体はコミット禁止、pushは明示的に依頼するまで保留です。まず現在の状態と未確定事項を報告してください。
```

## 個別作業を続ける場合

標準版の末尾へ、今回の具体的な依頼、期待する表示、確認対象ログを追記します。会話履歴だけに依存せず、新しく判明した解析仕様や判断は関連文書へ反映してください。
